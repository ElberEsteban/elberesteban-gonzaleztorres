# Portafolio Profesional — Elber Esteban González Torres

Portafolio web personal desarrollado como proyecto académico, basado en un diseño de Figma y adaptado a una paleta de escala de grises y negro. Presenta el perfil profesional, conocimientos, educación, certificaciones y portafolio de proyectos de **Esteban González**, estudiante de Ingeniería de Sistemas y analista con más de 15 años de experiencia en infraestructura TI.
